# Todo List

A simple and responsive Todo List application that helps users manage daily tasks. Users can add, delete, and manage their tasks through an easy-to-use interface.

## Features

- Add new tasks
- Delete tasks
- Mark tasks as completed
- Simple and clean user interface
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript

## Description

This project is a task management application developed using HTML, CSS, and JavaScript. It allows users to organize their daily activities by adding and managing tasks efficiently.
